المفهوم

أنواع الجمل الشرطية

جملة if البسيطة

if الشرط:
    العبارة

طريق واحد: تُنفَّذ العبارة إذا تحقق الشرط فقط.

جملة if…else

if الشرط:
    العبارة الأولى
else:
    العبارة الثانية

طريقان: الأول عند تحقق الشرط، والثاني عند عدم تحققه.

جملة if…elif…else

if الشرط الأول:
    العبارة الأولى
elif الشرط الثاني:
    العبارة الثانية
else:
    العبارة الثالثة

عدة شروط: يُنفَّذ أول فرع يتحقق شرطه فقط.

قواعد اللغة

أربع قواعد لا ننساها عند كتابة الشرط

١ النقطتان بعد الشرط

if grade >= 10:

النقطتان : ضروريتان بعد if و elif و else.

٢ المسافة البادئة

if grade >= 10:
    print("ناجح")

4 مسافات قبل العبارات التابعة للشرط.

٣ الكلمات بحروف صغيرة

if   elif   else

بايثون تفرّق بين الحروف: If خطأ، و if صحيح.

٤ المقارنة غير الإسناد

x = 5         # إسناد
if x == 5:    # مقارنة

داخل الشرط نستخدم == وليس =.

أدوات الشرطلو كانت x = 7

عوامل المقارنة والعوامل المنطقية

العاملالمعنىمثالالنتيجة
>أكبر منx > 5True
<أصغر منx < 5False
>=أكبر من أو يساويx >= 7True
<=أصغر من أو يساويx <= 6False
==يساويx == 7True
!=لا يساويx != 7False

and — كلا الشرطين

x > 5 and x < 10

كلاهما صحيح، النتيجة True

or — أحدهما يكفي

x < 0 or x > 6

الثاني صحيح، النتيجة True

النوع الأول

جملة if البسيطة

  • إذا تحقق الشرط True تُنفَّذ العبارة أو العبارات التي تتبع if.
  • إذا لم يتحقق الشرط False يتخطاها البرنامج ويكمل ما بعدها.
